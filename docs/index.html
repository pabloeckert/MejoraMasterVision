Preguntas puntuales

El modelo no diagnostica personas reales ni inventa credenciales. Con menores, solo sugiere preguntas para que se las hagas vos directamente.

Proyección de una serie (regresión lineal simple)

Proyección por tendencia lineal (mínimos cuadrados). Es una extrapolación estadística simple, no una predicción garantizada — sirve para ver hacia dónde apunta la tendencia actual, no para tomarla como certeza.

Equilibrio de Nash (estrategias puras, 2 jugadores)

Cada celda tiene el par (pago Fila, pago Columna). Un equilibrio de Nash en estrategias puras es una celda donde ningún jugador mejora cambiando su estrategia solo, dada la del otro.
